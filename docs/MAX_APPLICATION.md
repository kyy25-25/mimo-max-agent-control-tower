## Describe what you've built with agents or AI-driven workflows

I built **MiMo Max Agent Control Tower**, a multi-agent operations dashboard for planning, executing, auditing, and packaging AI-driven workflows. The project is designed for builders who use AI agents seriously and need a repeatable way to turn messy requests into structured, reviewable execution packages.

The system uses four specialist agents. The Intake Agent converts a raw user goal into a mission brief with users, constraints, desired outputs, and success metrics. The Planner Agent turns that brief into milestones, owners, risks, and acceptance tests. The Executor Agent generates implementation tasks, content, API action plans, and exportable artifacts. The Auditor Agent reviews every result for hallucination risk, privacy exposure, evidence quality, impact, and readiness.

Unlike a simple prompt demo, this project focuses on repeatable workflow orchestration. It shows how an AI builder can move from idea to execution with clear logs, confidence scoring, risk review, and proof packaging. The app is built with React and Vite, and its architecture is designed to connect to the Xiaomi MiMo API through a backend adapter for real model calls. It can also run in simulation mode so reviewers can inspect the workflow immediately.

This project demonstrates high-value agent usage because it combines planning, generation, evaluation, and evidence export in one loop. It is useful for developer teams, creators, founders, and operators who need to manage AI-heavy work with accountability instead of relying on one-off chat outputs.
